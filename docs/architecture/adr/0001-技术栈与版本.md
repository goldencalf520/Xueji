# ADR 0001：技术栈与版本

- 状态：已采纳（2026-10-11）
- 依据：产品文档 §13.1；本 ADR 记录落地时相对文档的调整及原因

## 决定

| 层 | 选型（锁定版本） | 相对文档 §13.1 的调整 |
|---|---|---|
| 运行时 | **Node.js 24 LTS** | 文档写 Node 20，但 Node 20 已于 2026-04 停止维护，改用当前 Active LTS |
| 包管理 / 构建编排 | pnpm 10 workspace + Turborepo 2 | 新增 Turborepo，按依赖顺序构建、缓存 |
| 语言 | TypeScript **5.9**（strict + noUncheckedIndexedAccess） | TS 7（Go 原生版）暂不采用：vue-tsc、NestJS 装饰器元数据、uni-app 工具链兼容性未验证 |
| 代码规范 | Biome 2（格式化 + Lint），`.vue` 由 vue-tsc 做类型检查 | 新增 |
| 后端 | **NestJS 11** + Express、nestjs-zod 5 + zod 4、@nestjs/swagger 11、nestjs-pino | NestJS 12 已改为 ESM-only，nestjs-zod 等生态尚未支持 12，待生态跟进后升级 |
| ORM | **Prisma 7.10** + `@prisma/adapter-mariadb`（MySQL 8） | Prisma 7 必须使用驱动适配器、`prisma.config.ts`；8.0 仍是 RC，不采用 |
| 队列 / 缓存 | Redis 7 + BullMQ 6（@nestjs/bullmq 11） | 与文档一致 |
| 规则引擎 | json-logic-js + `packages/rules` 纯函数 | 与文档一致 |
| AI | OpenAI 兼容接口（国内已备案模型）经 `packages/ai` 网关；腾讯云 ASR / TTS / 文本内容安全 | 与文档一致 |
| 管理端 / 医院端 / 移动工作台 | Vue 3.5 + Vite 8 + Element Plus 2（桌面）/ Vant 4（企微 H5）、Pinia 3、vue-router 4 | 移动工作台补充选用 Vant（文档未指定） |
| 小程序 | uni-app 3（`3.0.0-5020620260917001`）+ Vue **3.4.21** + Vite **5.2.8**、Pinia 2、wot-design-uni 1、uCharts | uni-app 官方锁定 Vue 3.4 / Vite 5.2.8，**不得单独升级**，须跟随 DCloud 发版统一升级 |
| 测试 | Vitest（各包）；服务端用 unplugin-swc 支持装饰器；Supertest 做接口测试；miniprogram-automator 做小程序 E2E | 文档写 Jest，统一改为 Vitest，一套配置覆盖全仓 |
| 部署 | 腾讯云 CVM + Docker Compose + Nginx；GitHub Actions | 与文档一致 |

## 落地中发现的平台约束（全员必须遵守）

1. **小程序 `wx.request` 不支持 PATCH**。用户端 `/api/v1/app/*` 的部分更新一律用 **PUT**：
   文档 §12.2 的 `PATCH /me`、`PATCH /me/settings`、`PATCH /family/links/{id}` 实现为 `PUT`。管理端、医院端可以使用 PATCH。
2. **Prisma 总是以 UTC 读写 DateTime**。数据库存 UTC；接口统一输出 `+08:00` 的 ISO 8601；
   "自然年、每月 1 日 03:00、每日" 等业务日期在应用层按 `Asia/Shanghai` 计算（dayjs + timezone）。这是对文档 §11.1 "统一存北京时间" 的调整。
3. **BIGINT 主键在接口中序列化为字符串**（`bootstrap.ts` 已设置全局 JSON replacer），契约里 ID 一律 `zId`（string）。
4. Prisma 7 生成的客户端输出到 `apps/server/src/generated/prisma`（不提交），`pnpm build / typecheck / test` 会自动先执行 `prisma generate`。

## 后果

- 依赖版本全部精确锁定（无 `^`），升级走 Dependabot PR + CI。
- 升级 NestJS 12 / TS 7 / Prisma 8 时各开独立 issue，需全量回归。
