# evals/ — AI 评测（§10.10、§17.5）

```text
evals/
├── plan/        # P1 方案文案评测集：150 个虚构客户案例（方案包 × 年龄段 × 标准/乐龄 × 有无就医建议）

```

所有案例均为虚构数据，不得使用真实客户信息。
